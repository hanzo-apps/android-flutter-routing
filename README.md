# android-flutter-routing

Declarative navigation with go_router — deep links, nested routes, auth guards.

**Lane:** Flutter · **Live demo:** https://android-flutter-routing.hanzo.app

## Run it on Android

```sh
flutter run -d android
```

## Provenance

Forked from [flutter/samples](https://github.com/flutter/samples) — `navigation_and_routing`, licensed **BSD-3-Clause**.
The upstream `LICENSE` is kept verbatim in this repo; the copyright stays with
its authors. Changes made here are limited to what a standalone fork needs
(see the initial commit).

## Preview

`flutter build web --release` produces the static bundle served at
https://android-flutter-routing.hanzo.app — the same app the Android build runs, rendered by
CanvasKit. It is a real running app, not a screenshot.
